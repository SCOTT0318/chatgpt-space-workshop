# ChatGPT Space · 3시간 기업 실무 워크숍

[교육 사이트 바로 열기](https://scott0318.github.io/chatgpt-space-workshop/)

임직원과 비개발 실무자를 위한 한국어 교육 사이트입니다. 회의·매출·고객문의에서 실행계획, 스프레드시트, 발표자료와 협업으로 이어지는 180분 워크숍을 제공합니다.

## 포함 내용

- 180분 운영표와 도넛형 일정 그래픽
- 20개 기능·연결 워크플로 안내, 검색과 분류
- 4개 업무의 입력 → AI 작업 → 사람 검토 → 결과 흐름도
- 중복 제거 전후의 매출·목표 비교 차트와 계산기
- 5단계 실습, 합성 자료 4개, 직무별 프롬프트 12개
- 강사 노트·모범답안, 6문항 퀴즈, 업무 적용 계획
- 전용 로고, 27개 UI 아이콘, 파비콘과 공유 미리보기 이미지

## 사용 방법

웹 주소를 열면 설치나 로그인 없이 교육자료를 볼 수 있습니다. 상단 **강사 노트**를 켜면 진행 메모와 정답을 표시합니다. **인쇄 / PDF**는 브라우저 인쇄 기능입니다. 실습 자료는 페이지 안에서 ZIP 또는 개별 파일로 내려받습니다.

기능 검색·계산기·퀴즈는 브라우저에서 작동합니다. 실습 체크만 localStorage에 저장하며 입력 내용을 외부 서버로 보내는 기능이나 분석 추적 스크립트는 포함하지 않습니다. 실제 ChatGPT 실습에는 별도 계정과 인터넷 연결이 필요합니다.

## 사이트 구성과 게시

빌드 도구 없이 동작하는 정적 사이트입니다. HTML·CSS·JavaScript·실습 자료는 `index.html`에 포함되어 있고 아이콘과 공유 이미지는 `assets/`에 있습니다. GitHub Pages의 `main` 브랜치 루트(`/`)를 게시 소스로 사용합니다. 이후 변경 사항도 해당 브랜치에 반영하면 갱신됩니다.

- `index.html`: 교육 본문과 인터랙션
- `assets/`: SVG 아이콘·PNG/ICO 파비콘·공유 이미지
- `site.webmanifest`: 홈 화면용 이름·아이콘
- `404.html`, `robots.txt`, `sitemap.xml`: 웹 기본 설정
- `.nojekyll`: 정적 파일 게시 설정

한빛오피스와 모든 실습 자료는 교육용 합성 데이터입니다. 회사 정책과 일치하지 않을 수 있습니다. 이 사이트는 OpenAI의 공식 교육·인증 자료가 아니며 로고와 아이콘은 이 교육을 위한 별도 디자인입니다.
