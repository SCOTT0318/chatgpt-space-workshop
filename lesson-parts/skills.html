# 회의 후속 정리
1. 지정한 자료만 읽는다.
2. 결정·아이디어·과제를 구분한다.
3. 없는 담당·기한은 미정으로 남긴다.
4. 근거와 함께 검토용 초안을 만든다.

폴더와 파일은 교육용 원본입니다. 내려받기만 해서는 등록되거나 실행되지 않습니다. 기본 제작은 자연어로 시작하고, 파일 기반 등록은 사용하는 환경의 설치 절차를 따릅니다.

스킬 예제 ZIPSKILL.md 보기·저장테스트 검토 기준
Project 공유와 스킬 배포는 별도로 확인합니다.

개인 스킬이 Project 공유만으로 동료에게 자동 등록되지는 않습니다. 지원되는 워크스페이스 스킬 공유 또는 플러그인 배포 경로를 확인하고, 동료가 사용할 수 있는 스킬·자료·연결 앱을 각각 점검합니다.
