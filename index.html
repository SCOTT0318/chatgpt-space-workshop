교육 범위와 제공 조건

ChatGPT Space의 공개된 공식 문서를 중심으로 작성했습니다. Space가 활성화된 계정이 필요하며 메뉴·연결 앱·편집·공유·예약 기능은 플랜, 배포 상태, 웹/데스크톱/모바일, 관리자 정책에 따라 다릅니다.

Spreadsheets의 Space 전용 고정 생성 메뉴는 가정하지 않습니다. 자연어 요청 후 실제 제공되는 파일·편집 형태를 확인합니다. Slides가 Windows에서 파일로 생성되면 웹이나 제공되는 cloud mode를 확인합니다.

이미지·웹 조사·Plugins·Skills·Voice·브라우저·예약 작업은 Space 문서와 연결하는 기능으로 소개했습니다. 가격·사용량·지원 플랜은 계정에서 별도로 확인합니다.

이 HTML 활용 방법

브라우저에서 파일을 열면 바로 사용할 수 있습니다. 외부 라이브러리·로그인·API 키가 필요하지 않습니다. 자료 다운로드·기능 검색·프롬프트·계산기·퀴즈는 로컬에서 작동합니다. 공식 출처 방문과 실제 ChatGPT 실습에는 인터넷이 필요합니다.

강사 노트를 켜면 진행 메모와 모범답안이 표시됩니다. 인쇄/PDF는 현재 강사 노트 상태를 따르고, 전체 기능 카드와 직무 프롬프트를 포함합니다. 별도 접근 제한이 있는 강사용 보안 문서는 아닙니다.

자료와 프롬프트는 교육용으로 만든 예시입니다. 한빛오피스와 등장 조직은 가상입니다. 이 교육자료는 OpenAI의 공식 교육·인증 자료가 아닙니다.
