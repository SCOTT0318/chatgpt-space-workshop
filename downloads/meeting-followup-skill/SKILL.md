# 회의 후속 정리

교육용 예제 v1.0 · 관리 역할: 팀 교육 담당자

제공받은 회의메모로 다음 행동이 보이는 검토용 초안을 작성한다.

## 사용할 입력

- 사용자가 지정한 회의메모와 관련 정책·참고 자료를 사용한다.
- 메모가 없거나 읽을 수 없으면 필요한 자료를 먼저 요청한다. 회의 내용을 만들어 채우지 않는다.

## 정리 기준

1. 메모에서 확정 결정, 검토 아이디어, 후속 과제, 미확인 사항을 구분한다.
2. 과제는 업무·담당·기한·상태·근거로 정리한다. 기록에 없는 담당·기한·상태는 `미정`으로 표시한다.
3. 고객 희망일과 확정 일정, 제안과 승인 결과를 구분한다. 근거가 없는 원인은 `미확인`으로 남긴다.
4. 날짜·수량·금액을 원문과 대조한다. 상대 날짜는 기준일이 명확할 때만 풀어 쓴다.
5. 결정과 과제에 자료명 또는 원문 위치를 연결해 검토자가 근거를 찾게 한다.

## 기본 결과

- 핵심 요약
- 확정 결정과 검토 아이디어
- 후속 과제 표: 업무 / 담당 / 기한 / 상태 / 근거
- 미확인 사항과 다음에 확인할 질문

사용자가 다른 형식을 정하면 그 형식을 따른다. Page 저장을 요청한 경우 사용할 수 있는 도구와 대상 위치를 확인하고, 저장할 수 없으면 채팅에 초안을 제공한다.

이 스킬은 메모 정리용이다. 메일 발송·일정 등록·공유 권한 변경을 정리 과정에 자동으로 덧붙이지 않는다.
